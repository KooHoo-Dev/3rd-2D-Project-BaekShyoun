# Title -  Observed

## 요약
- 방(실험실)에서 하루하루 재화를 벌며 욕구를 관리해 살아남는 게임

## 시점
- 탑다운 뷰

## 컨셉
- 취미가 고약한 부자들로 인해 어떤 방에 갇힌 플레이어는 매일매일 살아남아야 한다.

## 게임 종료 방식 (둘 중 택1)
- 게임 클리어 방식 : 살아남는 날의 한도(ex: 열흘 동안 살아남기)를 정한다.
	- 초반 며칠은 살아남기 쉽지만, 날이 갈 수록 재화 제한, 욕구 하락 속도 증가등으로 살아남기 어렵게 함
- 게임 오버 방식 : 한도 없이 최대한 오래 살아 남는 게 목표
	- 게임 클리어 후 살아남은 일수를 기록으로 남겨 기록 갱신 가능
---
## 핵심 시스템 : 모든 수치는 백분율로 숫자 100을 기준으로 한다.

### 시간 흐름 제어(턴 방식)
- 3시간 단위로 총 8턴 ( 00시 03시 06시 09시 12시 15시 18시 21시 )
- 미니게임 1턴, 수면 2턴 소모
- 수치 변화량
	- 미니게임 : 포만도 -30, 수분 -10, 에너지 -30
	- 일반 수면 : 포만도 -50, 수분 -30, 에너지 +20
	- 깊은 수면 : 포만도 -50, 수분 -30, 에너지 +40

### 플레이어
- 조작 : WASD로 상하좌우 이동, 각종 상호작용키(F키)
- 상태
	- 욕구 게이지 : 턴 진행 시 감소
		- 포만감(식욕) : 수치 100에 섭취시 질병 스택 +1, 수치 0에 미섭취 상태로 턴 진행 시 에너지 감소량(10) 증가
		- 수분(갈증) : 수치 100에 섭취시 질병 스택 +1, 수치 0에 미섭취 상태로 턴 진행 시 에너지 감소량(10) 증가
		- 에너지(수면욕) : 0이 될 시 강제 블랙 아웃 (2턴 동안 미니게임 판정으로 아무 재화도 얻지 못하고 스킵)
	- 디버프 : 조건부 발동
		- 질병
			- 포만감, 수분, 에너지 게이지가 스택에 따라 특정 배수(예시 : *1.2)만큼 더 많이 감소
			- 일반 수면 시 에너지 획득량 감소, 깊은 수면 시 영향 없음
			- 24시간(8턴)이 지나면 스택 -2 감소(스택 1일 시 0으로 초기화)
			- 3스택 달성 시 게임 오버

### 아이템
- 상호작용
	- Tab키를 누르면 인벤토리창이 뜸
	- 고기, 식수 : 우클릭 시 창이 뜨고 이 창을 통해 섭취, 폐기를 선택할 수 있다
	- 수면권 : 침대에서 상호작용 키를 누를 때 수면권을 사용할지 말지 선택하는 팝업창이 뜬다
- 식량 : 상호작용 시 포만감/수분 게이지가 참
	- 고기(하루 최대 획득량 5개, 포만감 +20)
		- 신선한 고기 : 부작용이 없는 고기 &  2턴 경과 시 부패한 고기로 변화
		- 부패한 고기 : 포만감 게이지는 차지만, 30%의 확률로 질병 스택 +1
		- 수상한 고기 : 포만감 게이지는 차지만, 3회 누적 섭취 시 질병 스택 +1
	- 식수(하루 최대 획득량 5개, 수분 +10)
		- 신선한 물 : 부작용이 없는 물. 4턴 경과 시 썩은 물로 변화.
		- 썩은 물 : 수분 게이지는 차지만, 30% 확률로 질병 스택 +1
	- 수면권 : 보유 시 '깊은 수면' 가능

### 맹수 : 맹수에게 음식을 주지 않으면 맹수가 우리를 탈출할 수 있음 (실제 추격전 X)
- 상호작용
	- 고장난 맹수 우리가 있고, 그 앞에 '맹수 관찰 단말기'가 있음
	- 맹수 우리에 상호작용 키를 누르면 맹수에게 먹이를 줄 수 있다
	- 단말기 앞에서 상호작용 키를 누르면 맹수의 탈출 충동 수치를 문구를 통해 짐작할 수 있음
		- 문구 예시 : "흥분 : 맹수가 이를 드러내고 플레이어를 노려봅니다."
- 상태
	- 탈출 충동 : 맹수가 우리를 탈출하게 하는 스탯
		- 1턴 지나면 +20만큼 증가(조건부 감소)
		- 맹수에게 고기 지급 시 -10
		- 0 ~ 25 안정 / 26 ~ 50 긴장 / 51 ~ 75 흥분 / 76 ~ 100 위험
		- 100 이상일 시 우리 탈출
			- 아래 공격 확률에 따라 플레이어가 사망하고 게임 오버될 수 있음
			- 수면을 1회 진행 후엔 새로운 맹수가 스폰됨
	- 공격 확률 : 맹수가 우리를 탈출하며, 허기를 채우기 위해 플레이어를 공격하게 하는 스탯
		- 0에서 조건부 증가, 높을 수록 플레이어를 공격할 확률이 높음
		- 공격하지 않을 경우, 그냥 탈출하고 우리는 비워지고 끝
		- 수상한 고기 섭취 시 +5

### 미니 게임(후보 중 택2)
- 상호작용
	- 오락기 앞에서 상호작용 키를 누름으로써 플레이 가능
	- 클리어 시 점수에 따라 포인트 획득
- 후보 (유력 후보는 **볼드체**)
	1. **페어 매칭** : 총 8장의 덮여 있는 카드가 있고, 두 장의 카드를 선택하여 뒤집어서 같은 종류의 카드일 시 포인트 획득
	1. **순서 기억하기** : 화면에 잠시 표시되는 순서를 기억한 뒤 동일한 순서대로 입력하는 미니 게임
	1. 타이밍 맞추기 : 움직이는 게이지를 특정 구간에서 멈춰 점수를 획득하는 미니 게임
	1. 두더지 잡기 : 제한 시간 동안 화면에 랜덤하게 나타나는 대상을 클릭하여 점수를 획득하는 미니 게임
	1. 슬롯머신 : 일확천금, 버튼 입력 시 무작위 결과에 따라 포인트를 획득하는 미니 게임
	1. 분류게임 : 여러 종류의 그림이 있고, 같은 종류의 그림 3개를 맞추면 포인트를 획득하는 미니 게임

### 교환
- 상호작용
	- 오락기 옆 교환 자판기에서 상호작용 키를 누름으로써 이용 가능
	- 각종 아이템을 게임 포인트로 교환할 수 있음
- 목록
	- 아이템
		- 신선한 고기(가격 예시 : 40pt)
		- 수상한 고기(가격 예시 : 30pt)
		- 식수(가격 예시 : 30pt)
		- 수면권(가격 예시 : 50pt)
	- (낮은 확률로)부자의 후원 : 포인트 대가 없이 아이템을 랜덤으로 받을 수 있음
